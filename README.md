# همراه تحصیلی | Smart Academic Advisor

اپلیکیشن Flutter فارسی برای راهنمایی تحصیلی از ابتدایی تا متوسطه، کنکور، دانشگاه و پس از فارغ‌التحصیلی. از الگوی رابط کاربری سبک و موبایل‌محور پروژه Smart Mechanic الهام می‌گیرد، اما محتوا و مسیرها مخصوص مشاوره تحصیلی طراحی شده‌اند.

## وضعیت فعلی

این commit یک نمونه اولیه رابط کاربری است، نه نسخه آماده انتشار:
- داشبورد فارسی و راست‌چین با طراحی روشن و سازگار با موبایل
- انتخاب مقطع از ابتدایی تا فارغ‌التحصیلی
- مسیرهای برنامه‌ریزی، انتخاب رشته، آزمون، کنکور، دانشگاه و شغل
- ثبت پرسش و نمایش پاسخ عمومی نمونه
- هنوز بدون سرور، کلید API، ورود، پرداخت یا ذخیره‌سازی ابری

**شفافیت مهم:** پاسخ فعلی توسط هوش مصنوعی تولید نمی‌شود. پیش از معرفی به‌عنوان مشاور هوشمند، سرویس AI باید با کلید امن، محافظت متناسب با سن دانش‌آموز و آزمون کیفیت پاسخ‌ها اضافه شود.

## اجرا

1. اجرای flutter create --platforms=android . برای تولید فایل‌های پلتفرم اندروید
2. اجرای flutter pub get
3. اجرای flutter analyze و flutter test
4. اجرای flutter run

برای ساخت APK آزمایشی از flutter build apk --debug استفاده کنید.

## نقشه توسعه

1. تکمیل پرسش‌نامه دانش‌آموز شامل پایه، رشته، هدف، زمان آزاد و چالش‌ها
2. اتصال امن به سرویس هوش مصنوعی از طریق backend؛ کلید API نباید داخل APK یا مخزن عمومی باشد
3. تاریخچه و برنامه شخصی به‌صورت local-first همراه با امکان حذف داده
4. راهنمای انتخاب رشته با تکیه بر علاقه، توانمندی و منابع رسمی؛ بدون وعده قبولی
5. ورود اختیاری و پرداخت درون‌برنامه‌ای سازگار با قوانین بازار
6. تست‌های خودکار، دسترس‌پذیری، حریم خصوصی کودکان و آماده‌سازی انتشار

## حریم خصوصی و ایمنی

اطلاعات دانش‌آموزان حساس تلقی شود. پیش از هر اتصال شبکه‌ای، جمع‌آوری حداقلی داده، اطلاع‌رسانی و رضایت متناسب با سن، امکان حذف داده و حفاظت از کلیدها باید طراحی و آزمایش شود. توصیه‌ها مکمل گفت‌وگو با خانواده و مشاور مدرسه هستند.
