# همراه تحصیلی | Smart Academic Advisor

اپلیکیشن Flutter فارسی و راست‌چین برای راهنمایی تحصیلی از ابتدایی تا کنکور، دانشگاه و پس از فارغ‌التحصیلی. از الگوی سبک و موبایل‌محور پروژهٔ Smart Mechanic الهام می‌گیرد، اما مسیرها و محتوا برای نیازهای تحصیلی طراحی شده‌اند.

## قابلیت‌های موجود در شاخهٔ main

- داشبورد فارسی با انتخاب مقطع و موضوع راهنمایی
- راهنمای قاعده‌محور متناسب با مقطع؛ این پاسخ آفلاین، خروجی هوش مصنوعی نیست
- ثبت کارهای درسی، علامت‌زدن انجام‌شدن و حذف کار\n- دفتر آزمون‌ها: شمارش معکوس تا تاریخ امتحان، ثبت نمره از ۲۰، میانگین نتایج و حذف آزمون؛ ذخیرهٔ محلی\n- تایمر تمرکز ۲۵ دقیقه‌ای با شروع، مکث و شروع دوباره؛ بدون نیاز به اینترنت\n- گزارش پیشرفت درس‌ها با ثبت مدت مطالعه و خودارزیابی تسلط، جمع زمان مطالعه و میانگین تسلط برای هر درس
- تعیین موعد برای هر کار درسی، نمایش کارهای موعد امروز و عقب‌افتاده و زمان‌بندی خودکار سه گام مرور آزمون، نمای هفتگی کارهای زمان‌بندی‌شده
- ساخت خودکار سه کار مرور از روی آزمون‌های آینده و افزودن آن‌ها به برنامهٔ درسی
- گزارش هفتگی زمان مطالعه با مقایسهٔ هفتهٔ جاری و قبل، تعداد کارهای انجام‌شده و درصد پیشرفت فعلی برنامه
- کارت‌های مرور فاصله‌دار برای سؤال و پاسخ شخصی؛ پاسخ سخت فردا و پاسخ درست با فاصلهٔ افزایشی تا ۶۰ روز دوباره نمایش داده می‌شود
- ساخت برنامهٔ پیشنهادی بر اساس زمان آزاد روزانه، نزدیک‌ترین آزمون و خودارزیابی تسلط درس‌ها؛ کارهای عقب‌افتاده به امروز منتقل می‌شوند
- مربی آموزشی سه‌مرحله‌ای: سرنخ، توضیح و بررسی یادگیری؛ در حالت آفلاین راهنمای عمومی ارائه می‌شود و در صورت تنظیم سرویس، درخواست برای پاسخ مرحله‌ای به سرور فرستاده می‌شود
- ارزیابی چهارپرسشی عادت‌های مطالعه با بازخورد غیرتشخیصی
- یادداشت‌ها و ترجیحات ذخیره‌شده روی دستگاه با امکان درخواست حذف
- اتصال اختیاری Flutter به API سمت سرور با `ADVISOR_API_BASE_URL`
- backend پایتون برای مدل‌های سازگار با Chat Completions، اعتبارسنجی ورودی و محدودیت اولیهٔ درخواست
- آزمون‌های Flutter و backend در GitHub Actions

## اجرای اپ

از ریشهٔ مخزن:

```bash
flutter create --platforms=android .
flutter pub get
flutter analyze
flutter test
flutter run
```

ساخت APK آزمایشی:

```bash
flutter build apk --debug
```

برای استفاده از مربی زندهٔ هوش مصنوعی، دو روش وجود دارد. روش پیشنهادی برای نسخهٔ عمومی، backend و کلید ذخیره‌شده روی میزبان است. اگر می‌خواهید کلید از GitHub Actions مستقیماً هنگام ساخت APK تزریق شود، Secret و Variables زیر را تنظیم کنید:

در GitHub مخزن، از **Settings → Secrets and variables → Actions** مقدار `AI_API_KEY` را به‌عنوان Secret اضافه کنید. در صورت نیاز، Repository Variables با نام‌های `AI_BASE_URL` و `AI_MODEL` را هم تنظیم کنید. Workflow ساخت APK این مقادیر را به `--dart-define` می‌دهد. مقادیر پیش‌فرض برای مدل‌های سازگار با API عبارت‌اند از `https://api.deepseek.com` و `deepseek-chat`.

برای اجرای محلی با backend واسط:

```bash
flutter run --dart-define=ADVISOR_API_BASE_URL=https://your-api.example
```

**توجه فنی:** کلیدی که داخل APK تزریق شود، دیگر محرمانه نیست و با مهندسی معکوس قابل استخراج است؛ این روش برای آزمایش و انتشار محدود قابل استفاده است، اما برای انتشار عمومی ممکن است کلید و هزینهٔ حساب را در معرض سوءاستفاده قرار دهد. برای نسخهٔ عمومی، استفاده از backend با کلید سمت سرور امن‌تر است.

اگر آدرس سرور تنظیم نشده باشد، اپ از راهنمای قاعده‌محور آفلاین استفاده می‌کند. اگر سرویس تنظیم شده اما در دسترس نباشد، راهنمای آفلاین نمایش داده می‌شود.

## اجرای backend

جزئیات در [راهنمای backend](backend/README.md) آمده است. نمونهٔ تنظیمات در `backend/.env.example` قرار دارد. در حالت backend، کلید واقعی را فقط در متغیر محیطی میزبان تنظیم کنید. در حالت ساخت مستقیم APK، از GitHub Actions Secret استفاده می‌شود، اما کلیدِ تزریق‌شده داخل APK قابل استخراج است.

اجرای آزمون‌های backend:

```bash
cd backend
pip install -r requirements.txt
python -m unittest -v test_app.py
```

## بررسی رقبا و مسیر توسعه\n\nتحلیل رقبا، قابلیت‌های اقتباس‌شده و اولویت‌های بعدی در [گزارش بررسی رقبا](docs/COMPETITOR_REVIEW.md) آمده است.\n\n## یادگیری مبتنی بر تسلط

بخش «نقشهٔ تسلط و اولویت یادگیری» با الهام از رویکرد تسلط‌محور سنگاپور و توجه ژاپنی به بررسی اشتباه‌ها، خودارزیابی درس‌ها را با نتایج کارت‌های مرور ترکیب می‌کند تا یک اولویت پیشنهادی ارائه دهد. این امتیاز صرفاً راهنمای شخصی است، نه آزمون علمی یا تشخیص قطعی توانایی.

## محدودیت‌های فعلی

- backend هنوز روی میزبان عمومی مستقر نشده و کلید ارائه‌دهنده تنظیم نشده است؛ بنابراین پاسخ زندهٔ هوش مصنوعی تا زمان پیکربندی و استقرار در دسترس نیست.
- محدودیت درخواست backend فعلاً درون‌حافظه‌ای است؛ برای انتشار واقعی به محدودسازی مشترک، HTTPS، پایش هزینه و تنظیمات قابل اتکای میزبان نیاز داریم.
- برنامه‌ها، یادداشت‌ها و دفتر آزمون روی همین دستگاه ذخیره می‌شوند؛ همگام‌سازی ابری و حساب کاربری وجود ندارد.
- ارزیابی مطالعه، تشخیص علمی یا سنجش هوش نیست. توصیه‌های مهم تحصیلی و انتخاب رشته باید با خانواده و مشاور مدرسه بررسی شوند.

## حریم خصوصی

پرسش‌ها فقط زمانی از اپ ارسال می‌شوند که آدرس backend در نسخهٔ نصب‌شده پیکربندی شده باشد. اطلاعات حساس یا شناسایی‌کنندهٔ غیرضروری وارد نکنید. پیش از انتشار عمومی، سیاست حریم خصوصی، حفاظت متناسب با سن کاربران، کنترل مصرف مدل، حذف داده و آزمون روی گوشی واقعی باید تکمیل شود.
