# همراه تحصیلی | Smart Academic Advisor

اپلیکیشن آموزشی فارسی و راست‌چین برای برنامه‌ریزی درسی، پیگیری آزمون‌ها، یادداشت‌ها، مرور فاصله‌دار و دریافت راهنمایی تحصیلی از مقطع ابتدایی تا دانشگاه.

> وضعیت پروژه: در حال توسعه. موفقیت CI به‌تنهایی به معنی آماده‌بودن برای انتشار عمومی نیست.

## قابلیت‌ها

- راهنمای آموزشی قاعده‌محور و آفلاین
- ارسال مستقیم درخواست هوش مصنوعی از گوشی به سرویس انتخابی کاربر
- ذخیره کلید API در حافظه امن Android Keystore از طریق `flutter_secure_storage`
- برنامه‌ریز درسی، تایمر تمرکز، آزمون‌ها و یادداشت‌های محلی
- کارت‌های مرور و مرور فاصله‌دار
- ارزیابی روش مطالعه و رابط فارسی/راست‌چین

## معماری و حریم خصوصی

این پروژه **هیچ بک‌اند اختصاصی، سرور Flask، API واسط، دیتابیس ابری یا حساب کاربری ندارد**.

- برنامه‌ریزی، یادداشت‌ها، آزمون‌ها و ترجیحات روی گوشی ذخیره می‌شوند.
- در صورت تنظیم‌نشدن AI، راهنمایی آفلاین فعال است.
- هنگام استفاده از AI، متن سؤال به‌همراه مقطع و موضوع انتخابی مستقیماً از گوشی به ارائه‌دهنده مدل ارسال می‌شود.
- کلید API را خود کاربر تهیه و در تنظیمات برنامه وارد می‌کند؛ کلید در کد، مخزن یا APK ثابت قرار نمی‌گیرد.
- کلید در حافظه امن دستگاه نگهداری می‌شود. این کار خطر استخراج را کاهش می‌دهد، اما در گوشی روت‌شده یا آلوده امنیت مطلق وجود ندارد.
- هزینه استفاده از مدل طبق تعرفه حساب کاربر نزد ارائه‌دهنده محاسبه می‌شود. سقف هزینه و محدودیت مصرف را در حساب همان ارائه‌دهنده تنظیم کنید.

## پیش‌نیازها

- Flutter 3.32 یا جدیدتر
- Dart 3.6 یا جدیدتر
- JDK 17 و Android SDK برای ساخت Android

## تنظیم اتصال هوش مصنوعی

1. در حساب خود نزد یک ارائه‌دهنده سازگار با API قالب OpenAI، کلید شخصی ایجاد کنید.
2. در برنامه وارد بخش **پروفایل ← تنظیمات هوش مصنوعی** شوید.
3. نشانی HTTPS سرویس، نام مدل و کلید API را وارد و ذخیره کنید.
4. برای نمونه تنظیمات پیش‌فرض DeepSeek عبارت‌اند از:
   - نشانی: `https://api.deepseek.com`
   - مدل: `deepseek-chat`

نشانی پایه می‌تواند شامل مسیر `/v1` نیز باشد. برنامه مسیر `/chat/completions` را به آن اضافه می‌کند. سرویس باید از قالب Chat Completions سازگار با OpenAI پشتیبانی کند.

**هرگز کلید واقعی را با `--dart-define`، در سورس، GitHub Actions یا فایل‌های مخزن قرار ندهید.** کلید تستی را نیز در Issue، گزارش خطا یا تصویر صفحه منتشر نکنید.

## ساختار پروژه

- `lib/config/`: ثابت‌های ظاهری و تنظیمات عمومی
- `lib/models/`: مدل‌های داده
- `lib/services/local_store.dart`: ذخیره محلی اطلاعات تحصیلی
- `lib/services/ai_settings_store.dart`: نگهداری امن تنظیمات AI روی دستگاه
- `lib/services/advisor_api.dart`: ارتباط مستقیم HTTPS با ارائه‌دهنده مدل
- `lib/services/offline_advice.dart`: راهنمایی آفلاین
- `lib/features/`: صفحات و قابلیت‌های برنامه
- `test/`: تست‌های واحد و رابط کاربری
- `.github/workflows/`: بررسی کیفیت و ساخت APK

## CI و انتشار

GitHub Actions تحلیل ایستای Flutter، تست‌ها و ساخت APK آزمایشی را اجرا می‌کند. فایل APK آزمایشی، نسخه امضاشده انتشار نیست.

برای ساخت نسخه امضاشده، Workflow دستی Android release از چهار Secret زیر استفاده می‌کند:

- `ANDROID_KEYSTORE_BASE64`
- `ANDROID_KEYSTORE_PASSWORD`
- `ANDROID_KEY_ALIAS`
- `ANDROID_KEY_PASSWORD`

فایل keystore و رمزهای آن را هرگز در مخزن قرار ندهید. چک‌لیست انتشار در [RELEASE_CHECKLIST.md](RELEASE_CHECKLIST.md) است.

## محدودیت‌های شناخته‌شده

- کلید API متعلق به خود کاربر است و مصرف مدل می‌تواند هزینه داشته باشد.
- سازگاری ارائه‌دهنده‌ها و نام مدل‌ها متفاوت است؛ نشانی و مدل را از مستندات رسمی همان سرویس بگیرید.
- داده‌های محلی با حذف برنامه یا پاک‌کردن داده‌های آن ممکن است از دست بروند؛ همگام‌سازی ابری وجود ندارد.
- تست روی دستگاه واقعی، بررسی دسترسی اینترنت، نگهداری امن کلید و سیاست حریم خصوصی پیش از انتشار نهایی ضروری است.
